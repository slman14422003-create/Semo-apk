# Semo — نسخة كوتلن أصلية (بدون WebView / بدون PWA)

هذه إعادة بناء كاملة لتطبيق "Semo/Tomodachi" بلغة Kotlin أصلية باستخدام
Jetpack Compose، بدل الإصدار السابق الذي كان WebView يحمّل حزمة ويب
(HTML/JS) من مجلد assets. لا يوجد أي HTML أو JavaScript في هذا المشروع
إطلاقاً - كل الواجهة والمنطق مكتوبان بالكوتلن مباشرة، ويتحدث التطبيق مع
نفس مشروع Firebase (semo-chat-f5fdf) ونفس أسماء المجموعات بفايرستور
(messages, users, stickers, badwords, bans, typing, blocked) حتى تبقى أي
بيانات موجودة مسبقاً متوافقة تماماً بدون أي هجرة.

## المُنجَز في هذه المرحلة
- تسجيل الدخول/إنشاء حساب (بنفس منطق اسم المستخدم + حظر/حظر مؤقت)
- الدردشة الحية: إرسال/استقبال فوري، رد على رسالة، حذف، مؤشر الكتابة،
  إرسال متفائل مع إعادة محاولة عند الفشل
- الستيكرات: إيموجي + صور مرفوعة (ضغط تلقائي قبل الرفع)، مفضّلة محلية
- الملف الشخصي: رمز تعبيري، نبذة، ثيم فاتح/داكن، لون فقاعة الرسائل
- لوحة المسؤول: إدارة المستخدمين (حظر دائم/مؤقت/تحذير متصاعد/ترقية/حذف)،
  الكلمات الممنوعة، إدارة الستيكرات، حذف كل الرسائل
- إشعارات الرسائل الجديدة حتى مع إغلاق التطبيق (خدمة Firestore أصلية
  بالخلفية، بدون WebView خفي كما كان سابقاً)

## قبل أول تشغيل
1. **google-services.json**: تم توليد نسخة تعمل من نفس بيانات مشروع
   Firebase الموجودة أصلاً بـ `js/firebase.js` (apiKey/projectId/...)، لكنها
   لا تقابل تطبيق أندرويد حقيقي مُسجَّل بلوحة Firebase Console. يُفضّل أن
   تضيف تطبيق أندرويد بحزمة `com.tomodachi.app` من Firebase Console
   وتنزّل ملف `google-services.json` الحقيقي وتستبدل به هذا الملف - خاصة
   لو أردت لاحقاً تفعيل Firebase Cloud Messaging أو Analytics.
2. **قواعد أمان Firestore**: تأكد من أن قواعد فايرستور بمشروعك تسمح
   بالقراءة/الكتابة اللازمة (المشروع الأصلي كان يعتمد على تحقق من
   `request.auth` - هذا التطبيق يسجّل دخولاً مجهولاً (Anonymous Auth) تلقائياً
   عبر Firebase Auth للحصول على uid حقيقي).
3. **Gradle Wrapper**: ملف `gradle/wrapper/gradle-wrapper.jar` غير مرفق
   (تعذّر تنزيله بدون اتصال شبكة وقت إنشاء هذا المشروع). افتح المشروع
   مباشرة في **Android Studio** وسيتكفّل بمزامنة/توليد الـ wrapper تلقائياً،
   أو نفّذ `gradle wrapper` يدوياً مرة واحدة إذا كان لديك Gradle مثبّت محلياً.

## أُضيف بالمرحلة الثانية
- لوحة إيموجي كاملة (938 رمز/10 تصنيفات، مطابقة لقاموس fullEmojis الأصلي
  حرفياً) + بحث بالتصنيف + تتبّع "الأخيرة" محلياً
- تفاعلات على الرسائل (❤️👍😂...) بالضغط المطوّل، وتعديل نص رسالتك،
  بنفس تحقق الملكية (uid ثم username احتياطياً) الموجود بالأصل
- ذاكرة تخزين محلية للرسائل (آخر 500، بدون بيانات الستيكرات الثقيلة) تظهر
  فوراً عند فتح التطبيق قبل اكتمال اتصال فايرستور
- 3 حزم ستيكرات مجانية افتراضية (أنمي/ردود أفعال/حيوانات، 30 ستيكر) تُدمج
  تلقائياً - **ملاحظة**: بدل SVG نصي كالأصل، تُرسَم هنا كشارات Compose
  متدرّجة اللون (أخف وأسرع)، فالشكل البصري مختلف قليلاً عن وجوه "التشيبي"
  الأصلية لأنمي بالذات

## غير مُطبَّق بعد (يمكن إضافته لاحقاً عند الطلب)
- رسم وجوه "تشيبي" الأنمي بنفس تفاصيل SVG الأصلية حرفياً (حالياً شارة
  مبسّطة برمز تعبيري بدل رسم العينين/الفم يدوياً)
- ضغط الرسائل (compressText/decompressText) وفلترة XSS اليدوية (DOMPurify)
  غير مطلوبتين أصلاً بالنسخة الأصلية لأن Compose لا يعرض HTML خام إطلاقاً
